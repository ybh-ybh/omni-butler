# Omni Butler v0.3.1 当前交付说明

## 1. 交付结论

当前仓库已经形成可运行的 Flutter 本地优先客户端、个人自托管的结构化数据同步，以及可选的物品/会员主图同步。第一期六个业务模块均具备本地数据闭环；同步默认关闭，用户通过服务器 IP 地址（或域名）、端口与同步密钥显式连接。

2026-09-30 已发布 v0.3.1（客户端 `0.3.1+4`），GitHub Release 包含 Android APK/AAB、Windows x64 Inno Setup 安装包、Windows 便携包和 SHA-256 清单。发布物已经生成不等于第一期正式验收完成：真实 Windows/Android 设备矩阵、通知、目标服务器、长期运行、发布签名与生产运维仍见 `剩余功能与验收清单.md`。

## 2. 客户端已存在能力

### 应用基础与平台布局

- GoRouter 提供首页、每日待办、事件、物品、24 小时时间记录、会员和设置 7 个一级业务入口。
- Windows 使用展开侧栏或紧凑导航轨；Android 紧凑布局使用底部导航，并通过“管理”聚合入口在事件、会员和物品之间切换。
- 单一飞书蓝语义主题支持跟随系统、浅色和深色；各业务模块可在本机独立开关。
- `N` 打开新增待办，`/` 打开全局搜索；全局搜索覆盖待办、事件、物品、时间记录、会员和名言。
- 普通用户记录使用客户端 UUID v7；每日选择、内置分类、重复任务等需要跨设备稳定身份的派生记录使用确定性 UUID。
- Windows 已有桌面层悬浮框和系统托盘。悬浮框提供重点待办、新增待办、开始记录和补记时间；位置及开关保存在本机，托盘可恢复主窗口、切换悬浮框或退出。

### 首页工作台与名言

- 首页由名言、当日刻度、重点待办、临近事件/会员和时间状态五类卡片组成，用户可在本机添加、移除和排序。
- 每日从启用名言中稳定选择一条，允许当天手动更换；名言库支持新增、编辑、启停、软删除、恢复和永久删除。
- 支持选择或移除本机横幅图片，并使用统一遮罩保持文字可读；首页横幅目前始终只保存在本机。
- 首页重点待办与每日待办共用全部未完成任务树及用户排序，不再把非当天计划的活动任务静默排除。

### 每日待办

- 支持新增、查看、编辑、完成/取消完成、软删除、恢复和永久删除。
- 支持计划日期、描述、截止时间、四象限优先分类、基础重复规则和提醒时间。
- 页面区分“进行中”和“完成历史”：全部未完成任务常驻进行中视图，完成历史按完成日期查询，并展示创建时间、完成时间和所属主任务。
- 支持“主任务—子任务”两级任务树；完成、重开、删除、恢复和象限移动均按任务树处理。
- 桌面端支持拖动根任务调整象限内顺序或跨象限移动；移动端提供等价菜单操作。
- 重复任务可按每天、每周、每月生成实例；重复主任务会复制有效子任务结构，并支持编辑或删除当前项及当前以后实例。

### 事件记录

- 支持新增、编辑、软删除、恢复、永久删除、归档和恢复归档。
- 支持天/周/月/年周期、提醒开关、提前天数和提醒时间。
- “记录现在”会生成完成历史、更新周期状态，并提供 6 秒撤销窗口。
- 支持历史备注、撤销状态和永久清理；活动事件默认按下次应做时间排列。

### 物品管理

- 支持新增、编辑、软删除、恢复和永久删除。
- 支持分类、数量、价格、购买日期/链接、位置、状态、保修、备注和标签。
- 支持主物品与配套物品关系，以及配套物品位置继承。
- 支持名称、分类、位置、标签和状态搜索/筛选；列表沿用当前默认排序，不提供购买时间/价格范围筛选和用户可选排序。
- 每件物品支持一张本机主图；服务器启用图片同步后可自动补传并在其他设备缓存。

### 24 小时时间记录

- 支持按日查看 00:00—24:00 时间轴，以及日/周/月复盘、类别结构、周期对比和趋势。
- 支持居中编辑器新增、查看、编辑和删除记录；补记滑动条按 5 分钟步进，并可用日期/时间控件输入实际值。
- 支持跨自然日区间、单条进行中记录、开始/结束快捷操作，以及按自然日切片统计。
- 保存时执行跨日重叠检查，支持相邻区间、空白区间和短区间查看。
- 支持时间类别管理和日、周、月分类耗时统计。

### 会员管理

- 支持新增、编辑、软删除、恢复和永久删除。
- 支持服务商、分类、标签、描述、官网、购买平台、价格、计费周期、购买/到期/续费信息、永久会员和取消说明。
- 支持续费/支付历史、到期提醒、续费提醒和月度/年度支出统计。
- 支持名称、服务商和分类搜索，以及状态和自动续费快捷筛选；会员标签用于信息维护和关联，不作为列表筛选条件。
- 每个会员支持一张本机主图；服务器启用图片同步后可自动补传并在其他设备缓存。

### 公共能力

- Drift/SQLite 本地数据库与正式迁移。
- 待办、事件、物品、时间、会员和名言统一回收站，支持 30 天清理。
- 分类与标签管理、业务关联和新记录稳定身份。
- Windows/Android 本地通知计划、模块开关和测试通知入口；系统权限流程和真机触发仍待补齐/验收。
- 共享按钮、输入、下拉、开关、面板、标签、对话框、侧边面板、日期和时间浮层。
- 成功、提示、警告和错误反馈统一使用窗口顶部浮动消息，支持自动关闭、手动关闭和可选撤销。

## 3. 自托管同步已存在能力

### 客户端连接与迁移

- 设置页填写服务器 IP 地址（或域名）、端口与同步密钥；固定 API 路径由客户端自动拼接。
- 连接前会预检服务器身份，并展示本机/服务器记录数、回收站数量和本机待上传数量。
- 首次连接当前采用双方合并；已经绑定其他数据源时，用户可选择以本机覆盖目标服务器，或采用服务器数据替换本机。
- 跨数据源迁移使用候选数据库、独立会话、写入门禁、持久迁移 ID、服务端原子回执和请求检查点。中断后可继续，成功后原数据库和逻辑快照保留为迁移备份。
- PowerSync 与 Drift 访问同一 SQLite 文件，支持本地 CRUD 捕获、事务批量上传和增量下行。
- 设置页和桌面侧栏显示连接、上传、下载、待上传数量及错误状态。
- 断开时可选择保留或清空结构化同步数据；本机附件文件的清理语义仍需修正。

### 设备会话

- 连接成功后获得最长 15 分钟的 Access Token、固定期限且不轮换的高熵设备凭证，以及 PowerSync 专用短期 JWT。
- 设备凭证只保存摘要于服务端，刷新不会延长其固定期限；客户端对并发 401 使用 singleflight，并防止断开后的迟到响应恢复旧会话。
- 显式断开会删除服务端设备会话；已签发 PowerSync JWT 最多继续有效到其短期期限结束。

### 服务端

- NestJS 运行时包含认证、同步、图片、Prisma 和健康检查模块。
- 空数据库自动创建内部数据所有者；它只用于数据归属，不是用户账号。
- 同步接口通过表、操作和字段白名单接收 PowerSync 事务，并强制注入当前内部所有者；事务身份和回执用于幂等重试。
- 提供连接预检、服务器快照替换、迁移状态查询、PowerSync JWT 和 JWKS。
- 容器启动执行 Prisma migration；PowerSync publication 由正式 migration 创建。

### 当前同步范围

- 结构化同步：待办、名言、每日名言选择、分类、标签关联、事件及历史、物品、时间记录、会员及支付历史。
- 可选图片同步：服务器设置 `IMAGE_SYNC_ENABLED=true` 后，物品和会员主图通过认证 API 与内置私有 MinIO 传输；支持离线重试、版本冲突保护、摘要校验、本机缓存、清空标记和永久删除后的对象回收。
- 仅保存在本机：首页横幅、本机应用偏好、迁移控制元数据及图片缓存路径。图片二进制和图片同步清单不进入 PowerSync Schema。

## 4. 部署与发布

`deploy/` 提供 PostgreSQL 17、NestJS 与 PowerSync 的 Docker Compose 编排、环境变量样例、数据库初始化和 PowerSync 配置。

- PostgreSQL 使用持久化卷并启用逻辑复制；业务数据库端口默认不暴露到宿主机。
- API 容器执行 migration、健康检查和服务初始化；PowerSync 镜像固定版本与摘要，并使用 PostgreSQL bucket storage。
- `IMAGE_SYNC_ENABLED=true` 时启动固定版本的内置 MinIO，图片数据和随机内部凭证分别保存到持久卷，MinIO 不向宿主机公开端口。
- Compose 默认项目名为 `omni-butler`。旧部署升级必须沿用原项目名，避免误连一组新卷。
- 当前固定 MinIO 镜像无法再从 Docker Hub 直接拉取；新服务器需从可信机器导入经摘要校验的镜像归档。
- `.github/workflows/release-clients.yml` 在版本标签推送后验证客户端，生成签名 Android APK/AAB、Windows 安装包/便携包并发布校验清单。
