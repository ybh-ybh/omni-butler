| 项目 | 内容 |

本版依据用户确认的 Windows 笔记页面重构计划，替代旧版的笔记类别、Windows 自动提交、独立详情布局和打开即新建正式记录等定义。笔记用于记录想法、工作进展及生活感受，以正文、平铺标签、归档日期和原音整理。标题取正文首个非空行，不新增标题字段。

## 1. 范围与平台策略

- Windows 参考用户提供的三张截图：左侧统计及热力图、标签与回收站，右侧新建输入框和单列紧凑历史卡片。
- Windows 使用本机草稿及显式“发布／保存”；Android 保持既有页面、录音交互及自动保存，只移除类别并使用笔记独立回收站。
- 彻底移除笔记类别及 notes/category 管理项和关联，其他模块类别保持完整。只保留笔记标签，不设层级、文件夹或笔记本。
- 沿用 Omni 控件、项目主题、六套配色、明暗模式、大字号和减少动画设置。
- Windows 新增受限 Markdown 可视编辑与多图附件，格式仅包含加粗、下划线、高亮及单层有序／无序列表。Android 不新增对应界面，共享数据层保存和另存须保全图片。
- 暂不增加 AI 摘要、自动日报周报、链接解析或协作分享；正文可以粘贴链接但不抓取网页。
- 本轮交付代码、迁移、测试及中文预览，不部署正式服务器，不清理真实用户笔记。

## 2. Windows 页面与导航

### v2.13 标签置顶与两级删除菜单

置顶状态按标签身份在同账号设备间同步。Windows 在全部标签上方显示“置顶标签”，为空时隐藏；置顶项仍出现在全部标签中，两处筛选、计数一致，统计不重复累加。置顶区沿用原标签排序，不受全部标签的搜索与折叠影响。Android 保留原界面并保全共享置顶字段。

三个点菜单依次为“置顶／取消置顶”“编辑名称/图标”、分隔线及带右箭头的红色“删除标签”；图标使用完整emoji字符串，空值恢复井号，不增加移动层级。删除项悬停或点击展开二级菜单：“仅删除标签”“删除标签和笔记”。两面板均240dp宽，12dp圆角，复用Omni行高、主题边框、阴影和动效；二级菜单默认右侧4dp间距，与删除行顶部对齐，窗口边缘翻转／钳制。主子面板属于同一窗口内路由，支持方向键、Enter／Space及两级Escape，选择只回调一次。

“仅删除标签”解除全部笔记（含回收站）中的关联并保留内容。“删除标签和笔记”确认篇数后将本机已知的全部关联活动正式笔记移入30天回收站，包含有其他标签的笔记；原正文、版本、图片及原音保留。已有回收记录不刷新期限，恢复笔记不恢复该标签。删除前等待相关录音／图片／文字可靠暂存；整个事务保持门禁，失败整体回滚，确认对象变化须重新确认。未发布草稿保留，当前历史修改沿用冻结及另存／取消入口。

### v2.12 编辑栏与图片补充

- 工具从左到右为井号、图片、分隔线、Aa、无序列表、有序列表。单个工具悬停时图标加深且显示浅灰圆角底色；格式启用及 Aa 弹层打开时保持选中反馈。发布／录音沿用主题色。
- Aa 上方横向弹出加粗、下划线、高亮；选区操作后恢复焦点与原选区，Escape 或点击外部关闭。Ctrl+B／Ctrl+U 仅在正文中切换格式，无选区则作用于后续输入。
- 正文持久化为 `**加粗**`、`<u>下划线</u>`、`==高亮==`、`- 项目`、`1. 项目`；编辑与阅读直接显示效果。列表回车续项、空项回车退出、行首退格退出，支持多行选区切换类型，不提供嵌套。其他语法保留为文字。
- 保留普通首行派生标题；列表开头整段渲染，不拆首项。标题、搜索与字数使用可见文字；复制正文保留 Markdown。版本仅恢复正文，不回滚当前图片。
- 图片按钮一次选择多张 PNG／JPEG／WebP。首张成功导入后显示正文下方缩略图区，68dp 图片、8dp 间距、末尾虚线加号；删除末图时整区隐藏。缩略图可放大，超宽自然换行。
- 原图最终保存至现有私有 MinIO；本机副本用于离线草稿与查看缓存。单图上限 20MB、4000 万像素。共用图片同步开关，断网或旧服务器暂不支持时保留待传，恢复后补传。
- 图片增删跟随本机草稿，发布／保存后才进入正式记录和同步。支持纯图片发布；取消恢复原图，另存创建独立图片身份；差量提交保留其他设备新增图片。
- 数据升级为 SQLite 20、同步 schema 5、本机快照 5；服务端换服快照协议仍为 3。先升级数据库／API／PowerSync，再升级所有参与同步的客户端，不操作正式部署。

进入笔记页时全局导航收窄为图标。当前视图位于顶栏左侧，笔记搜索位于右上角，Ctrl+F 聚焦搜索；删除此处的全局搜索、本机草稿和外观模式三个按钮。

2026-10-16按两段搜索参考视频补充：搜索框默认灰底且无可见边框，高度由48dp缩小10%至43.2dp；鼠标悬停出现中性细边框，聚焦后变为白底并从260dp向左展开至400dp，窄窗受可用宽度限制，大字号保留必要高度，减少动画即时切换。右侧过滤按钮打开窗口内上下文面板，时间范围永久展开、无折叠箭头；标签和包含内容默认折叠。所有标题默认灰色，悬停、键盘导航或已有有效条件时仅文字与箭头变正文色，不绘制整行背景；其余两组点击标题显示选项。时间支持本月、上月、近7天、近30天及包含首尾日的自定义日期；所有选项按钮使用截图中的浅灰底、细描边、居中文字，选中后为浅主题色底、主题色细边框与文字，不增添勾选或类型图标；搜索按钮用实主题色，重置为灰色文字。标签支持包含、不包含、无标签及名称搜索；空查询不列标签，输入后仅显示匹配的井号按钮，选中后清空查询并在输入区保留可移除的小标签；包含内容支持图片、正文HTTP/HTTPS链接和语音多选，条件按交集生效。搜索应用菜单草稿，重置只清空菜单草稿，取消不改已应用条件；无来源字段，不显示来源筛选。

聚焦搜索时在框下显示最多5条真实本机搜索历史，最近使用在前，支持点击或上下方向键加回车选择，Escape或外部点击关闭。仅明确提交或在过滤面板点击搜索才记录关键词，忽略空白、大小写不敏感去重，不把中文组合输入保存成历史。历史只在本机偏好中持久化，不新增同步或数据库字段。

笔记侧栏默认 264dp、独立滚动，可拖动分隔条在 220–340dp 间调整宽度。仅鼠标停留在分隔热区时显示浅灰线，鼠标按下立即变为主题色，松开后恢复悬停状态，闲置时透明；指示线顶部和底部各留24dp空白。鼠标在整个笔记侧栏内（包括功能、标签、回收站及底部空白）时，在右上角显示“隐藏侧边栏”；隐藏整个笔记侧栏后，在主区视图标题左侧显示恢复按钮。隐藏／恢复及拖动保留当前草稿、筛选和会话内宽度。顺序固定：

1. 全部正式笔记数、全部有效笔记标签数、有笔记的天数；数字和文字分别左对齐、居中、右对齐。
2. 热力图随侧栏宽度显示最近 8–12 周，最小宽度为 8 列，最大宽度为 12 列，每列一周，纵向周一至周日；深浅表示数量。有笔记的日期悬停显示“2026-10-12·1 篇笔记”格式的日期与篇数，点击筛选当天，再次点击取消；空日期和未来日期点击无效，保留当前视图及筛选，不显示提示。底部使用“七月”“十一月”等中文月份，取消“近13周”等说明；中文标签保持完整，过近月份只保留较新月份以免重叠。
3. 唯一功能入口“全部笔记”。
4. “置顶标签”：存在置顶项时显示，保留该项在全部标签中的原位置。
5. “全部标签”：显示用户定义的全部有效标签，包括未使用的标签；点击单个标签筛选，新增及完整管理入口位于侧栏标题悬停工具中的“管理标签”，替代原排序按钮。
6. “回收站”：只处理笔记。

侧栏隐藏时向左滑出并淡出，主区随占位宽度同步扩展，展开沿反向路径恢复。沿用220ms面板动效，动画中途反向从当前呈现进度继续；拖动宽度保持跟手。隐藏开始即停用侧栏点击、键盘焦点和读屏内容，恢复按钮始终在主区可用。

标签区域悬停显示管理、搜索和每个标签的正式笔记数量；单行悬停时右侧篇数替换为三个点菜单，操作见v2.13。三个点字形、按钮背景和所属行内容垂直同心居中。标题行悬停时“全部标签”从灰色变为主题正文色，文字右侧显示折叠箭头，不绘制灰色悬停或按下背景；折叠仅隐藏全部标签行，置顶标签及回收站仍可见。标签列表以标题下方为锚点，220ms向下展开、向上收起，回收站随列表高度移动；中途反向从当前高度继续，收起立即停用列表点击、焦点及读屏。减少动画即时切换。标签列表与回收站之间不添加额外区块留白，沿用相邻行间距。标题文字左边缘对齐回收站可见图标的左边缘；窄侧栏大字号时工具换到下一行，保留四字标题完整。

标签搜索点击后用搜索输入替换标题行，并展开列表；输入框为36dp高、12dp圆角、不透明浅灰填充，无焦点描边，搜索图标嵌入左侧、关闭按钮嵌入右侧。只匹配标签名称，与主区笔记搜索及筛选独立。搜索无结果时列表直接为空，不显示提示文字或保留空态占位。关闭按钮或Escape清空标签查询并恢复完整列表。管理入口打开笔记标签管理器，支持新增、重命名、删除与拖动维护持久化顺序，不再提供侧栏会话排序菜单；主区查询与回收站不影响篇数。

全部标签下的每个标签与回收站使用和“全部笔记”一致的行高，常规字号下视觉高度40dp，保留4dp相邻行间距；右侧菜单不额外撑高标签。各项统一无额外纵向内边距，名称单行省略，放大字号时按同一行规范适配。

Windows普通图标按钮及图标式菜单共享28dp圆角方形背景、36dp布局及点击热区、18dp居中字形和零内边距。未悬停的中性图标使用灰色，仅鼠标悬停自身或键盘聚焦时使用主题正文色（浅色黑、深色白）。明确业务语义颜色与嵌入式约束保留，Android保留48dp触控热区。隐藏入口、标签工具、折叠指示及数量／菜单切换统一120ms原位淡入淡出，允许中途反向；隐藏立即停用点击、焦点及读屏，减少动画时即时切换。

“编辑名称”打开小型Omni弹窗，显示井号图标、原名称输入和保存按钮；校验空白及重复名称，失败保留输入，成功保留标签身份、颜色、置顶和原排序。没有层级标签。删除标签后从两个分区移除，并清理失效筛选；远端同步删除同样生效。

热图每格四周4dp留白，相邻格间距8dp；悬停120ms放大到1.2倍而不改变布局，并显示手形光标。有正式笔记且非未来日期悬停时，方块边框及光晕使用主题色，离开后收回；空日期只有放大反馈。减少动画模式下侧栏即时切换、方块保持原尺寸，有笔记日期仍保留即时主题色反馈。

统计与热图只计算未删除正式笔记，包含纯录音，排除未发布草稿；天数按 dayKey 去重。搜索及筛选不改变统计。页面可用宽度不足 900dp 时侧栏收进抽屉，隐藏状态不影响抽屉入口；恢复宽窗后沿用此前隐藏状态和宽度。主区标题固定，输入框与历史列表共同滚动。

三项统计数量与名称均可打开同一个“记录统计”居中弹窗。悬停时数字和文字由灰色变为正文色，名称右侧箭头以120ms淡入并轻微右移，移出反向收回，数字和名称原有左／中／右对齐不移动。显示手形，支持Tab、Enter和Space及统一内容按压；减少动画即时切换。弹窗年份入口悬停、按下及菜单关闭后保留焦点时均无底色；月／年入口显示手形，只有未选中项在悬停时显示深灰背景，选中项保持滑块原色，点击切换后鼠标停留原位也不得出现黑底。

记录统计弹窗最大1120×780dp、四周至少24dp留白，背景遮罩和轻模糊；居中标题、关闭按钮、月／年分段和年份选择固定，正文独立滚动。不显示分享、更多和“查看更多统计分析”。每次打开默认月视图，当前年有正式笔记时默认当前年，否则最新有记录年份；年份下拉倒序，只包含有正式笔记的年份，当前项显示主题色勾选。切换月／年保留年份。当前年从当前月倒排到一月，历史年从十二月倒排到一月，保留零记录月份；月卡随窗口和字号显示三／二／一列。

月卡显示月份、篇数、字数及记录天数；日历从周一开始，日期数字在方块上方，各卡固定六周高度。空日期悬停仅绘制主题色细边框，普通光标、无提示且点击无效；有记录日期使用主题色深浅表示数量，悬停主题色边框、手形及“N笔记·M字”提示。月首尾占位不响应交互。点击有效日期关闭弹窗及侧栏抽屉，清空主区搜索、标签、未打标签和其他时间条件，退出回收站，显示当天全部正式笔记并滚动到顶部；重复选择同一天保持筛选，通过“全部笔记”恢复。仅改变筛选，不取消或发布当前草稿及历史编辑。

年视图显示笔记、字数、记录天数三张年度合计卡及十二个月柱图，横轴01–12、右侧整数刻度，蓝／绿／红沿用主题语义色；零值为零高度。统计按稳定dayKey聚合，正文字符数沿用编辑器可见字符口径，包含空白和标点，独立原音转写不重复计数，纯录音计1篇和1记录日、0字。弹窗监听正式数据变化，当前年份最后一篇消失后回退最新有效年份；全空时显示空态并隐藏年份菜单。加载、失败和真实空态区分，失败可重试，加载或错误不重置所选年份。弹窗日期格与旧侧栏热图分别呈现，旧热图交互沿用。

主区顶部为新建输入卡片，随内容增高。按2026-10-13补充的四张截图呈现：白色圆角表面、浅灰常态轮廓，聚焦显示细主题色边框和轻阴影；占位“现在的想法是...”，正文悬停不出现背景填充或分隔线。底部左侧按 v2.12 提供标签、图片与格式工具，未聚焦为极浅灰、聚焦为灰色，悬停单独加深并显示浅灰背景；右侧48×30dp主操作只有20dp白色发布／麦克风图标。有文字、图片或有效原音时显示主题色发布按钮；空白时显示主题色麦克风，点击才申请权限并录音。聚焦时在主操作左侧显示字符数（中文、组合字符及emoji按可见字符计数），失焦隐藏；移除取消按钮、日期、状态文字及更多工具入口。录音期间仍提供暂停、继续、结束，异常和待恢复原音保留必要提示／恢复入口。新建默认归档今天，不继承筛选日期；当前未完成编辑沿用应用级本机草稿的暂存及重启恢复。深色模式沿用主题表面和可读灰色，操作颜色跟随当前主题。

## 3. 本机草稿、提交及冲突

保留一个应用级编辑控制器和录音器；Windows 显式提交，Android 自动保存。两张本机草稿表不加入 PowerSync 同步表：顶部保留一个新建草稿，每篇历史笔记最多一份编辑草稿，同时只激活一个编辑器。

输入停顿 500ms、连续输入最长 2 秒暂存；切换、失焦和退出前立即暂存，重启恢复。Windows 的 flush() 只保存本机草稿，区分“尚未落盘”与“尚未发布”；后台转写和远端更新必须保护所有未发布草稿。

发布／保存在同一事务中提交正文、不可变版本、标签和新增录音，明确返回成功、冲突或失败。只有成功才删除草稿并收起编辑器。失败保留正文和原音；冲突可采用最新版本或另存新笔记，不静默覆盖。保存和取消过程中不能切换草稿身份；等待本草稿的全部录音落盘任务完成后才能提交。

输入卡片不提供取消按钮；切换卡片只暂存，保留原正式笔记与正式原音。底层放弃草稿时仍须清除本次新增原音并保留正式内容，已放弃的代次不能被迟到事件复活。手动插入转写和采用历史版本在 Windows 中先修改草稿，提交后才更新正式版本和插入元数据。

空白输入、仅改标签或日期且无有效音频不生成正式笔记。已有正式笔记清空正文不等同于删除，只有显式删除才进入回收站。标签管理项独立于草稿，可保留尚未使用的标签。

## 4. 录音与转写

用户点击麦克风才申请权限并开始录音；默认不因进入页面自动录音。支持暂停、继续、结束、回听及播放位置调整。暂停不计入时长，单段最多 30 分钟，单篇累计最多 60 分钟；到限保存可用原音，不能自动开始下一篇。

Windows 录音绑定独立 draftId 和代次，浏览其他笔记不改变归属；提交只结束属于当前草稿的录音。草稿原音先保存本机，发布后才提升为正式附件。取消、永久删除和孤儿清理必须检查全部正式及草稿引用，不能误删其他笔记的共享原音。

崩溃恢复的原音回到草稿，不自动生成正式笔记；取消后的迟到录音事件不复活草稿。恢复清单必须先确认数据库归属后再确认消费。缺失或摘要不匹配的原音阻止提交并保留草稿，不能伪报成功。

默认在发布／保存后，按现有授权启动上传与转写。Android 保留原来的录音结束后异步处理。原始音频、原始转写、人工正文分别存储；转写结果不得覆盖未发布修改。重新转写默认产生候选，由用户确认插入；没有有效文字仍保留原音。

既有方案沿用 MinIO 私有原音桶 omni-butler-note-audio 和后端腾讯云 ASR 适配器。客户端不保存供应商长期密钥，不在查看同一片段时重复创建计费任务。撤回授权后停止未开始任务，已发送任务如实说明可能已送达；删除或切换数据源后的迟到结果不得写入新数据源。

后台、最小化及正常锁屏时已启动录音继续。操作系统休眠、麦克风被抢占、权限撤回或应用真正退出导致中断时保留可用部分，恢复不自动开启麦克风。Android 持续通知及后台行为沿用现有实现，必须另行真机验收。

## 5. 日期与标签

创建时间、创建时区保持原始记录语义，dayKey 表示用户归档自然日，允许按既有规则补记过去日期。修改正文或标签不把旧笔记移到今天。跨时区保留 dayKey，时间按当前设备展示；新建不能继承热图选中日期。

标签属于 notes/tag，不与其他模块自动合并。复用现有标签管理、查重、颜色和排序；名称含斜杠作为普通字符，不产生层级。置顶使用is_pinned独立字段，改名及排序不覆盖该字段；删除行为由用户在二级菜单选择，有效标签统计包括未使用的定义项。

不提供笔记类别新增、选择、重命名或类别搜索；旧 notes/category 管理项和关联在升级中退休，不改变物品、会员等模块类别。

## 6. 回收站及数据源

回收站仓储支持 general / notes / all 范围，查询与清空均按范围执行。设置回收站使用 general、排除笔记；笔记回收站使用 notes；到期自动清理用 all，仍为 30 天。

软删除冻结关联草稿，恢复后可继续；本机永久删除及到期清理同时清除关联草稿和录音。远端删除遇到本机未提交修改时保留冲突副本，仅允许另存或丢弃，不恢复原记录。成功另存的独立笔记及其原音引用不随原记录删除。

本机数据库快照及备份包含草稿与原音，计入空间预算并按摘要校验；草稿不进入服务端迁移暂存区。换服务器选择本机数据时携带草稿；选择服务器数据时，旧草稿只留在旧数据源及备份，不混入新数据源。
