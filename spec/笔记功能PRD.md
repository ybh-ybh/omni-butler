本版依据用户确认的 Windows 笔记页面重构计划，替代旧版的笔记类别、Windows 自动提交、独立详情布局和打开即新建正式记录等定义。笔记用于记录想法、工作进展及生活感受，以正文、平铺标签、归档日期和原音整理。标题取正文首个非空行，不新增标题字段。

## 1. 范围与平台策略

- Windows 参考用户提供的三张截图：左侧统计及热力图、标签与回收站，右侧新建输入框和单列紧凑历史卡片。
- Windows 与 Android 均使用本机草稿及显式“发布／保存”；Android 默认进入全部正式笔记列表，新建使用根导航紧凑面板，历史及其恢复草稿使用全屏编辑。笔记使用独立回收站。
- 彻底移除笔记类别及 notes/category 管理项和关联，其他模块类别保持完整。只保留笔记标签，不设层级、文件夹或笔记本。
- 沿用 Omni 控件、项目主题、六套配色、明暗模式、大字号和减少动画设置。
- Windows 新增受限 Markdown 可视编辑与多图附件，格式仅包含加粗、下划线、高亮及单层有序／无序列表。Android v2.15 通过底部面板复用富文本、多图及原音草稿能力，共享数据层保存和另存须保全图片。
- 暂不增加 AI 摘要、自动日报周报、链接解析或协作分享；正文可以粘贴链接但不抓取网页。
- 本轮交付代码、迁移、测试及中文预览，不部署正式服务器，不清理真实用户笔记。

## Android 页面（v2.15，搜索细化 v2.16，输入与录音细化 v2.17）

- 默认正式列表按现有归档日与创建时间倒序；卡片使用首行派生标题及两行正文，单篇展开阅读，附有效标签、图片及紧凑原音。v2.18已有笔记菜单与全屏历史编辑规则见下节，取代原简版三项菜单及历史底部面板。
- 保留主界面全局导航；底部输入栏视觉高度47.6dp（较56dp减少15%），三个入口保持至少48dp触控。文案为“点击输入或长按语音”；单击文字编辑，长按与麦克风均进入录音、松手继续，加号弹出拍照／选择图片。抽屉、搜索、编辑均在根导航覆盖，交互不穿透底栏。Android 宽屏笔记自行提供顶栏，底层导航不随覆盖层键盘缩小。
- 编辑面板默认200dp、可跟手拉高至安全可用高度95%，随实际系统键盘inset贴边且不追加延迟动画；正文与附件独立滚动、底部工具栏固定。正文、归档日、标签、图片、原音统一暂存本机；新建点击发布、历史点击保存才正式入库并同步。空白不创建正式笔记；失败、冲突、冻结及另存沿用既有控制器。
- 文字遮罩、下滑和收起均先可靠暂存，失败保留面板；系统返回先关闭工具浮层或键盘，再暂存收起。放弃更改经确认才取消当前代次。录音退出改为“继续／退出”确认，退出只清除本次片段；应用进入后台仍沿用前台服务采集，权限失败可重试，保留原音恢复及转写授权。
- 左侧抽屉为屏宽82%、最大360dp；包含全量正式统计、近12周热图、全部笔记、草稿、置顶／全部标签及回收站。标签搜索、管理及菜单入口在触屏常驻；删除复用既有两种删除事务。统计在Android使用整屏可用宽度，选日返回列表且保留草稿。
- 独立搜索初始不弹键盘、不继承列表筛选；关键词检索可见正文、有效标签和原始转写。快捷条件为无标签、链接、图片、语音、那年今日，组合取交集。那年今日仅匹配归档日期为往年同月同日，排除今年；闰日不折算相邻日期。
- 筛选面板独立暂存时间、标签包含／排除／无标签、内容类型及往年同日；应用才回写，取消不变，重置只重置面板草稿。选择指定标签退出无标签模式，失效标签不参与筛选；搜索取消恢复主列表位置和条件。
- 本轮不新增服务端接口、数据库或同步协议版本；既有正式笔记保持原样，新增行为只改变Android呈现与草稿提交策略。

### v2.16 搜索页按视频细化

- 空关键词在快捷搜索下显示最近搜索，空历史整块隐藏；垃圾桶直接清空本机历史，不改关键词和结果。继续使用 `notes.search.history` 存储键、五条上限、首尾去空白及大小写无关去重；清空与提交共用串行写入队列。
- 键盘搜索、点击历史、确认过滤及打开结果阅读／编辑时记录完整关键词；输入和取消不记录。组合区由搜索框保留到提交门禁检查，中文组词期间不提前提交；点击历史按当前已应用条件查询。Windows 保持既有提交行为。
- 快捷入口横向间距8dp、无额外行间留白，视觉最小40dp、触控至少48dp；大字号自然换行，空查询区连同最近搜索整体滚动。
- 过滤改为自然高度、顶部圆角和半透明遮罩的根导航面板。顶栏为向下箭头、居中筛选、按需显示的重置图标和确认勾。默认日期／标签／内容三行，普通行最小56dp，右侧为灰色摘要和双向箭头；不新增笔记来源。
- 日期菜单仅不限时间、本周、本月、自定义；复用现有日期控件，包含首尾自然日。那年今日快捷保留，选择其他日期范围清除它。标签菜单为不限／无标签／包含指定／排除指定；不限和无标签清除指定集合，包含或排除至少一个有效标签才可确认。
- 内容菜单为所有内容、有图片、有链接、有语音，保持交集多选，每次切换关闭菜单；所有内容清空，多选摘要为已选N项。紧凑圆角浮层以行右下角定位，选中使用主题色与右勾，旋转和屏幕边缘自动避让。重置只改草稿，确认才应用，关闭、遮罩、下滑及返回取消普通筛选修改。
- 指定标签切换到同一覆盖层中的独立视图：×／选择标签／✓，搜索框及现有顺序平铺列表、右侧圆形多选，不新增层级。自动聚焦，支持清空和取消搜索，搜索不丢已选；✓确认子草稿、×取消，返回先收键盘再回过滤视图。键盘从面板总高度扣除，短屏保留工具与滚动列表；摘要显示首个标签，多选补充等N个。实时删除的标签不允许作为唯一指定条件提交。
- 本轮不改变共享查询匹配、数据库或同步协议，使用项目现有主题色与Omni控件。

## Android 输入与录音 v2.17

- 文字表面顶部24dp圆角及横条；工具依次为标签、图片、加粗、列表、更多，右侧麦克风和发送。文字非空隐藏常驻麦克风；更多含高亮、下划线、笔记选项、拍照、撤销和重做，列表提供单层有序／无序。笔记选项承接归档日、转写授权、恢复、版本及放弃。
- 编辑与录音共享一层背景模糊和主题遮罩；文字进入300ms、语音进入280ms、退出220ms、工具160ms、发送状态120ms。拖动接管当前高度并吸附，减少动画取消位移及连续波形滚动。
- 录音卡片为REC／归档日、实际PCM音量、时长及实际额度；录制暂停／停止，暂停继续／停止，停止取消／确认。单段30分钟、单篇60分钟保留；可视采样最多20Hz，隐藏和后台关闭可视化。系统中断与限额结束只进入确认态。
- 主页录音先可靠保存原草稿，再建立独立空语音草稿，确认直接发布，退出或成功后恢复原草稿；编辑内录音确认只加入原稿。退出均先确认，只取消当前片段。方法返回与完成事件共用原音队列，原生桥传递草稿代次，迟到和重复完成按录音ID幂等。
- 拍照和相册通过官方image_picker进入系统界面；外部启动前保存数据源／草稿／请求身份。私有仓储以稳定附件ID导入，冷启动retrieveLostData恢复；取消和旧数据源结果不得挂入当前篇，失败保留清单重试。主页成功后打开原稿展示附件、先不弹键盘。
- 本轮无数据库、服务端接口和同步协议变化；Windows继续沿用原编辑呈现和共享控制器。详细验证和设备限制见[笔记交付说明](../apps/client/docs/notes-redesign.md)。

- 历史版本用移动端只读面板展示完整正文；取消不换草稿，恢复后打开对应全屏页，只替换正文，保留标签和附件，仍需保存生效。编辑内版本工具复用同一移动面板。
- 删除复用回收站确认与prepareForDeletion事务，成功退出对应编辑页，失败原位保留；未发布修改保留冻结草稿，其他笔记录音不停止。菜单及异步结果绑定源与笔记身份，远端删除或源变化停止操作；全屏源变化时连同本页选择器退出。
- 搜索结果编辑只记录当前完整搜索词，不重新提交查询；返回保留关键词、过滤、展开及滚动。另一篇录音不能被当前历史页接管，返回原录音先暂存退出当前页，再打开原代次。
- 不增加数据库、API或同步协议，不改变Windows呈现与默认Omni菜单行为。验证证据见[笔记交付说明](../apps/client/docs/notes-redesign.md)。

## 2. Windows 页面与导航

### v2.13 标签置顶与两级删除菜单

置顶状态按标签身份在同账号设备间同步。Windows 在全部标签上方显示“置顶标签”，为空时隐藏；置顶项仍出现在全部标签中，两处筛选、计数一致，统计不重复累加。置顶区沿用原标签排序，不受全部标签的搜索与折叠影响。Android在v2.19采用独立呈现并保全共享置顶字段。

三个点菜单依次为“置顶／取消置顶”“编辑名称/图标”、分隔线及带右箭头的红色“删除标签”；图标使用完整emoji字符串，空值恢复井号，不增加移动层级。删除项悬停或点击展开二级菜单：“仅删除标签”“删除标签和笔记”。两面板均240dp宽，12dp圆角，复用Omni行高、主题边框、阴影和动效；二级菜单默认右侧4dp间距，与删除行顶部对齐，窗口边缘翻转／钳制。主子面板属于同一窗口内路由，支持方向键、Enter／Space及两级Escape，选择只回调一次。

“仅删除标签”解除全部笔记（含回收站）中的关联并保留内容。“删除标签和笔记”确认篇数后将本机已知的全部关联活动正式笔记移入30天回收站，包含有其他标签的笔记；原正文、版本、图片及原音保留。已有回收记录不刷新期限，恢复笔记不恢复该标签。删除前等待相关录音／图片／文字可靠暂存；整个事务保持门禁，失败整体回滚，确认对象变化须重新确认。未发布草稿保留，当前历史修改沿用冻结及另存／取消入口。

### v2.12 编辑栏与图片补充

- 工具从左到右为井号、图片、分隔线、Aa、无序列表、有序列表。单个工具悬停时图标加深且显示浅灰圆角底色；格式启用及 Aa 弹层打开时保持选中反馈。发布／录音沿用主题色。

## 3. 本机草稿、提交及冲突

保留一个应用级编辑控制器和录音器；Windows 与 Android 均显式提交，自动保存只暂存本机草稿。两张本机草稿表不加入 PowerSync 同步表：顶部保留一个新建草稿，每篇历史笔记最多一份编辑草稿，同时只激活一个编辑器。

输入停顿 500ms、连续输入最长 2 秒暂存；切换、失焦和退出前立即暂存，重启恢复。Windows 的 flush() 只保存本机草稿，区分“尚未落盘”与“尚未发布”；后台转写和远端更新必须保护所有未发布草稿。

发布／保存在同一事务中提交正文、不可变版本、标签和新增录音，明确返回成功、冲突或失败。只有成功才删除草稿并收起编辑器。失败保留正文和原音；冲突可采用最新版本或另存新笔记，不静默覆盖。保存和取消过程中不能切换草稿身份；等待本草稿的全部录音落盘任务完成后才能提交。

输入卡片不提供取消按钮；切换卡片只暂存，保留原正式笔记与正式原音。底层放弃草稿时仍须清除本次新增原音并保留正式内容，已放弃的代次不能被迟到事件复活。手动插入转写和采用历史版本在 Windows 中先修改草稿，提交后才更新正式版本和插入元数据。

空白输入、仅改标签或日期且无有效音频不生成正式笔记。已有正式笔记清空正文不等同于删除，只有显式删除才进入回收站。标签管理项独立于草稿，可保留尚未使用的标签。

## 4. 录音与转写

用户点击麦克风才申请权限并开始录音；默认不因进入页面自动录音。支持暂停、继续、结束、回听及播放位置调整。暂停不计入时长，单段最多 30 分钟，单篇累计最多 60 分钟；到限保存可用原音，不能自动开始下一篇。

Windows 录音绑定独立 draftId 和代次，浏览其他笔记不改变归属；提交只结束属于当前草稿的录音。草稿原音先保存本机，发布后才提升为正式附件。取消、永久删除和孤儿清理必须检查全部正式及草稿引用，不能误删其他笔记的共享原音。

崩溃恢复的原音回到草稿，不自动生成正式笔记；取消后的迟到录音事件不复活草稿。恢复清单必须先确认数据库归属后再确认消费。缺失或摘要不匹配的原音阻止提交并保留草稿，不能伪报成功。

默认在发布／保存后，按现有授权启动上传与转写。Android仅确认发布／保存后进入正式上传与转写流程，录音结束先可靠暂存本机。原始音频、原始转写、人工正文分别存储；转写结果不得覆盖未发布修改。重新转写默认产生候选，由用户确认插入；没有有效文字仍保留原音。

既有方案沿用 MinIO 私有原音桶 omni-butler-note-audio 和后端腾讯云 ASR 适配器。客户端不保存供应商长期密钥，不在查看同一片段时重复创建计费任务。撤回授权后停止未开始任务，已发送任务如实说明可能已送达；删除或切换数据源后的迟到结果不得写入新数据源。

后台、最小化及正常锁屏时已启动录音继续。操作系统休眠、麦克风被抢占、权限撤回或应用真正退出导致中断时保留可用部分，恢复不自动开启麦克风。Android 持续通知及后台行为沿用现有实现，必须另行真机验收。

## 5. 日期与标签

创建时间、创建时区保持原始记录语义，dayKey 表示用户归档自然日，允许按既有规则补记过去日期。修改正文或标签不把旧笔记移到今天。跨时区保留 dayKey，时间按当前设备展示；新建不能继承热图选中日期。

标签属于 notes/tag，不与其他模块自动合并。复用现有标签管理、查重、颜色和排序；名称含斜杠作为普通字符，不产生层级。置顶使用is_pinned独立字段，改名及排序不覆盖该字段；删除行为由用户在二级菜单选择，有效标签统计包括未使用的定义项。

不提供笔记类别新增、选择、重命名或类别搜索；旧 notes/category 管理项和关联在升级中退休，不改变物品、会员等模块类别。

## 6. 回收站及数据源

回收站仓储支持 general / notes / all 范围，查询与清空均按范围执行。设置回收站使用 general、排除笔记；笔记回收站使用 notes；到期自动清理用 all，仍为 30 天。

软删除冻结关联草稿，恢复后可继续；本机永久删除及到期清理同时清除关联草稿和录音。远端删除遇到本机未提交修改时保留冲突副本，仅允许另存或丢弃，不恢复原记录。成功另存的独立笔记及其原音引用不随原记录删除。

本机数据库快照及备份包含草稿与原音，计入空间预算并按摘要校验；草稿不进入服务端迁移暂存区。换服务器选择本机数据时携带草稿；选择服务器数据时，旧草稿只留在旧数据源及备份，不混入新数据源。
