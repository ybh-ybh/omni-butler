本版依据用户确认的 Windows 笔记页面重构计划，替代旧版的笔记类别、Windows 自动提交、独立详情布局和打开即新建正式记录等定义。笔记用于记录想法、工作进展及生活感受，以正文、平铺标签、归档日期和原音整理。标题取正文首个非空行，不新增标题字段。

## 1. 范围与平台策略

- Windows 参考用户提供的三张截图：左侧统计及热力图、标签与回收站，右侧新建输入框和单列紧凑历史卡片。
- Windows 使用本机草稿及显式“发布／保存”；Android 保持既有页面、录音交互及自动保存，只移除类别并使用笔记独立回收站。
- 彻底移除笔记类别及 notes/category 管理项和关联，其他模块类别保持完整。只保留笔记标签，不设层级、文件夹或笔记本。
- 沿用 Omni 控件、项目主题、六套配色、明暗模式、大字号和减少动画设置。
- 本轮不增加富文本、图片、AI 摘要、自动日报周报、链接解析或协作分享。正文可以粘贴链接，但不抓取网页。
- 本轮交付代码、迁移、测试及中文预览，不部署正式服务器，不清理真实用户笔记。

## 2. Windows 页面与导航

进入笔记页时全局导航收窄为图标。笔记页顶栏取代重复的全局搜索栏，保留全局搜索图标和外观入口；当前视图位于左侧，笔记搜索位于右上角，Ctrl+F 聚焦搜索。

笔记侧栏默认 264dp、独立滚动，可拖动分隔条在 220–340dp 间调整宽度。仅鼠标停留在分隔热区时显示浅灰线，鼠标按下立即变为主题色，松开后恢复悬停状态，闲置时透明；指示线顶部和底部各留24dp空白。鼠标在整个笔记侧栏内（包括功能、标签、回收站及底部空白）时，在右上角显示“隐藏侧边栏”；隐藏整个笔记侧栏后，在主区视图标题左侧显示恢复按钮。隐藏／恢复及拖动保留当前草稿、筛选和会话内宽度。顺序固定：

1. 全部正式笔记数、全部有效笔记标签数、有笔记的天数；数字和文字分别左对齐、居中、右对齐。
2. 热力图随侧栏宽度显示最近 8–12 周，最小宽度为 8 列，最大宽度为 12 列，每列一周，纵向周一至周日；深浅表示数量。有笔记的日期悬停显示“2026-10-12·1 篇笔记”格式的日期与篇数，点击筛选当天，再次点击取消；空日期和未来日期点击无效，保留当前视图及筛选，不显示提示。底部使用“七月”“十一月”等中文月份，取消“近13周”等说明；中文标签保持完整，过近月份只保留较新月份以免重叠。
3. 唯一功能入口“全部笔记”。
4. “全部标签”：显示用户定义的全部有效标签，包括未使用的标签；点击单个标签筛选，新增及完整管理入口位于侧栏标题悬停工具中的“管理标签”，替代原排序按钮。
5. “回收站”：只处理笔记。

侧栏隐藏时向左滑出并淡出，主区随占位宽度同步扩展，展开沿反向路径恢复。沿用220ms面板动效，动画中途反向从当前呈现进度继续；拖动宽度保持跟手。隐藏开始即停用侧栏点击、键盘焦点和读屏内容，恢复按钮始终在主区可用。

标签区域悬停显示管理、搜索和每个标签的正式笔记数量；单行悬停时右侧篇数替换为三个点菜单，只提供“删除标签”和“编辑名称”。三个点字形、按钮背景和所属行内容垂直同心居中。标题行悬停时“全部标签”从灰色变为主题正文色，文字右侧显示折叠箭头，不绘制灰色悬停或按下背景；折叠仅隐藏标签行，回收站仍可见。标签列表以标题下方为锚点，220ms向下展开、向上收起，回收站随列表高度移动；中途反向从当前高度继续，收起立即停用列表点击、焦点及读屏。减少动画即时切换。标签列表与回收站之间不添加额外区块留白，沿用相邻行间距。标题文字左边缘对齐回收站可见图标的左边缘；窄侧栏大字号时工具换到下一行，保留四字标题完整。

标签搜索点击后用搜索输入替换标题行，并展开列表；输入框为36dp高、12dp圆角、不透明浅灰填充，无焦点描边，搜索图标嵌入左侧、关闭按钮嵌入右侧。只匹配标签名称，与主区笔记搜索及筛选独立。搜索无结果时列表直接为空，不显示提示文字或保留空态占位。关闭按钮或Escape清空标签查询并恢复完整列表。管理入口打开笔记标签管理器，支持新增、重命名、删除与拖动维护持久化顺序，不再提供侧栏会话排序菜单；主区查询与回收站不影响篇数。

全部标签下的每个标签与回收站使用和“全部笔记”一致的行高，常规字号下视觉高度40dp，保留4dp相邻行间距；右侧菜单不额外撑高标签。各项统一无额外纵向内边距，名称单行省略，放大字号时按同一行规范适配。

Windows普通图标按钮及图标式菜单共享28dp圆角方形背景、36dp布局及点击热区、18dp居中字形和零内边距。未悬停的中性图标使用灰色，仅鼠标悬停自身或键盘聚焦时使用主题正文色（浅色黑、深色白）。明确业务语义颜色与嵌入式约束保留，Android保留48dp触控热区。隐藏入口、标签工具、折叠指示及数量／菜单切换统一120ms原位淡入淡出，允许中途反向；隐藏立即停用点击、焦点及读屏，减少动画时即时切换。

“编辑名称”打开小型Omni弹窗，显示井号图标、原名称输入和保存按钮；校验空白及重复名称，失败保留输入，成功保留标签身份、颜色和原排序。没有层级标签。“删除标签”沿用确认框及解除关联仓储，只删除标签及关联，保留正文、版本、原音和未发布草稿；删除当前选中的标签后移除失效筛选。

热图每格四周4dp留白，相邻格间距8dp；悬停120ms放大到1.2倍而不改变布局，并显示手形光标。有正式笔记且非未来日期悬停时，方块边框及光晕使用主题色，离开后收回；空日期只有放大反馈。减少动画模式下侧栏即时切换、方块保持原尺寸，有笔记日期仍保留即时主题色反馈。

统计与热图只计算未删除正式笔记，包含纯录音，排除未发布草稿；天数按 dayKey 去重。搜索及筛选不改变统计。页面可用宽度不足 900dp 时侧栏收进抽屉，隐藏状态不影响抽屉入口；恢复宽窗后沿用此前隐藏状态和宽度。主区标题固定，输入框与历史列表共同滚动。

主区顶部为新建输入卡片，随内容增高。按2026-10-13补充的四张截图呈现：白色圆角表面、浅灰常态轮廓，聚焦显示细主题色边框和轻阴影；占位“现在的想法是...”，正文悬停不出现背景填充或分隔线。底部左侧只保留`#`标签入口，未聚焦为极浅灰、聚焦为灰色；右侧48×30dp主操作只有20dp白色发布／麦克风图标。有文字或有效原音时显示主题色发布按钮；空白时显示主题色麦克风，点击才申请权限并录音。聚焦时在主操作左侧显示字符数（中文、组合字符及emoji按可见字符计数），失焦隐藏；移除取消按钮、日期、状态文字及更多工具入口。录音期间仍提供暂停、继续、结束，异常和待恢复原音保留必要提示／恢复入口。新建默认归档今天，不继承筛选日期；未完成编辑通过页头本机草稿恢复。深色模式沿用主题表面和可读灰色，操作颜色跟随当前主题。

Windows输入框移除“管理标签”按钮。标签沿用物品管理标签筛选的紧凑圆角气泡、无勾选图标、描边与选中层级，保留多选语义，选中色使用当前笔记主题。已选标签常驻显示；未选标签只有点击`#`选择图标才展开，再次点击收起。可选区约220ms向下弹出／向上收回，同时淡入淡出与轻微缩放，允许中途反向；开始隐藏即排除点击、键盘焦点和读屏。选择仅暂存当前草稿，发布才正式关联；Android选择及管理入口沿用。

Windows提示图标、菜单按钮、笔记输入工具及热图提示分别保留独立语义边界；标签、正文和编辑动态区域保持稳定父节点，防止浮层锚点合并或多层重挂导致AXTree更新失败。保留完整读屏、键盘操作与悬停提示，不关闭无障碍功能、不屏蔽引擎日志、不修改本机Flutter SDK。

版本记录保留在历史卡片的“笔记操作”菜单，自动转文字开关在录音期间的控制区提供，均不增加常态输入工具。

历史卡片默认按 dayKey、创建时间倒序；收起时展示灰色10dp创建时间、一行标题和最多两行摘要。摘要取首个非空行之后的内容，避免重复；纯录音标题“语音笔记”。右上操作菜单常态灰色，悬停使用主题正文色及手形光标。双击原地向下展开相同样式的输入卡片，后续卡片随之下移，使用图标保存；左侧显示灰色“取消”，点击丢弃本次正文、录音插入及删除草稿并恢复正式笔记。切回写新笔记时暂存本次修改并保留正式正文。最多展开一张历史卡片，菜单“编辑”作为替代入口。展开沿用约 220ms 动效，尊重减少动画。

正文超过两行时，在预览下方、音频上方显示灰色“展开”，悬停变主题蓝字与手形光标，不增加背景。点击完整展开后按钮变“收起”；两方向以约220ms高度动画推动后续内容，最多一篇正文展开，打开其他篇时收起上一篇，尊重减少动画。正文阅读展开独立于双击编辑；进入编辑会收起其他正文，编辑中展开另一篇正文先暂存现有本机草稿。

收缩笔记卡片保留圆角和独立底色，不显示边框描边；历史笔记处于编辑状态时，输入框主题色边框常驻，失焦仍保持，直到取消或结束编辑。

有原音的收缩卡片在正文下显示浅灰音频条，包含播放／暂停、细进度线、小圆点、两位分钟时长和“更多”。点击“更多”向下展开12dp灰色原始转写；只保留“重新识别”和“下载”，文字操作悬停浅灰圆角背景和手形光标。原文展开与笔记编辑独立；重新识别沿用已有授权和任务身份，未知回执期间不创建重复任务。下载将经长度和SHA校验的原始WAV字节保存到用户所选位置，取消不影响原件；本机原音未就绪或校验失败时禁用播放和下载。Windows历史编辑沿用相同紧凑音频条，展开原文后增加“插入正文”和右侧红色垃圾桶“删除录音”；插入优先采用当前候选，没有候选时用原始转写。删除只进入本机草稿，重启可恢复，保存才原子移除本篇所选片段元数据，取消保留原音，另存不会修改原篇；共享原件仍由既有引用清理机制保护。草稿新增录音同样使用音频条，正式发布前禁用重新识别。Android沿用完整录音管理界面。

搜索匹配正文、有效标签及原始转写，与日期和标签筛选取交集。“全部笔记”清除所有筛选。全局搜索定位指定笔记并原地展开，重复定位也必须可靠；筛选切换和编辑不无故重置滚动位置。

## 3. 本机草稿、提交及冲突

保留一个应用级编辑控制器和录音器；Windows 显式提交，Android 自动保存。两张本机草稿表不加入 PowerSync 同步表：顶部保留一个新建草稿，每篇历史笔记最多一份编辑草稿，同时只激活一个编辑器。

输入停顿 500ms、连续输入最长 2 秒暂存；切换、失焦和退出前立即暂存，重启恢复。Windows 的 flush() 只保存本机草稿，区分“尚未落盘”与“尚未发布”；后台转写和远端更新必须保护所有未发布草稿。

发布／保存在同一事务中提交正文、不可变版本、标签和新增录音，明确返回成功、冲突或失败。只有成功才删除草稿并收起编辑器。失败保留正文和原音；冲突可采用最新版本或另存新笔记，不静默覆盖。保存和取消过程中不能切换草稿身份；等待本草稿的全部录音落盘任务完成后才能提交。

输入卡片不提供取消按钮；切换卡片只暂存，保留原正式笔记与正式原音。底层放弃草稿时仍须清除本次新增原音并保留正式内容，已放弃的代次不能被迟到事件复活。手动插入转写和采用历史版本在 Windows 中先修改草稿，提交后才更新正式版本和插入元数据。

空白输入、仅改标签或日期且无有效音频不生成正式笔记。已有正式笔记清空正文不等同于删除，只有显式删除才进入回收站。标签管理项独立于草稿，可保留尚未使用的标签。

## 4. 录音与转写

用户点击麦克风才申请权限并开始录音；默认不因进入页面自动录音。支持暂停、继续、结束、回听及播放位置调整。暂停不计入时长，单段最多 30 分钟，单篇累计最多 60 分钟；到限保存可用原音，不能自动开始下一篇。

Windows 录音绑定独立 draftId 和代次，浏览其他笔记不改变归属；提交只结束属于当前草稿的录音。草稿原音先保存本机，发布后才提升为正式附件。取消、永久删除和孤儿清理必须检查全部正式及草稿引用，不能误删其他笔记的共享原音。

崩溃恢复的原音回到草稿，不自动生成正式笔记；取消后的迟到录音事件不复活草稿。恢复清单必须先确认数据库归属后再确认消费。缺失或摘要不匹配的原音阻止提交并保留草稿，不能伪报成功。

默认在发布／保存后，按现有授权启动上传与转写。Android 保留原来的录音结束后异步处理。原始音频、原始转写、人工正文分别存储；转写结果不得覆盖未发布修改。重新转写默认产生候选，由用户确认插入；没有有效文字仍保留原音。

既有方案沿用 MinIO 私有原音桶 omni-butler-note-audio 和后端腾讯云 ASR 适配器。客户端不保存供应商长期密钥，不在查看同一片段时重复创建计费任务。撤回授权后停止未开始任务，已发送任务如实说明可能已送达；删除或切换数据源后的迟到结果不得写入新数据源。

后台、最小化及正常锁屏时已启动录音继续。操作系统休眠、麦克风被抢占、权限撤回或应用真正退出导致中断时保留可用部分，恢复不自动开启麦克风。Android 持续通知及后台行为沿用现有实现，必须另行真机验收。

## 5. 日期与标签

创建时间、创建时区保持原始记录语义，dayKey 表示用户归档自然日，允许按既有规则补记过去日期。修改正文或标签不把旧笔记移到今天。跨时区保留 dayKey，时间按当前设备展示；新建不能继承热图选中日期。

标签属于 notes/tag，不与其他模块自动合并。复用现有标签管理、查重、颜色、排序和删除语义；名称含斜杠作为普通字符，不产生层级。标签删除不删除正文或原音，有效标签统计包括未使用的定义项。

不提供笔记类别新增、选择、重命名或类别搜索；旧 notes/category 管理项和关联在升级中退休，不改变物品、会员等模块类别。

## 6. 回收站及数据源

回收站仓储支持 general / notes / all 范围，查询与清空均按范围执行。设置回收站使用 general、排除笔记；笔记回收站使用 notes；到期自动清理用 all，仍为 30 天。

软删除冻结关联草稿，恢复后可继续；本机永久删除及到期清理同时清除关联草稿和录音。远端删除遇到本机未提交修改时保留冲突副本，仅允许另存或丢弃，不恢复原记录。成功另存的独立笔记及其原音引用不随原记录删除。

本机数据库快照及备份包含草稿与原音，计入空间预算并按摘要校验；草稿不进入服务端迁移暂存区。换服务器选择本机数据时携带草稿；选择服务器数据时，旧草稿只留在旧数据源及备份，不混入新数据源。
